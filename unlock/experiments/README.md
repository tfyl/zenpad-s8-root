# Historical experiments

These files record earlier approaches. The final unlock implementation is in
[`../src/set_unlock_flag.c`](../src/set_unlock_flag.c).

| File | Status |
|---|---|
| `set-unlock-flag-v3-x86` | Earlier diagnostic build (v3) |
| `set-unlock-flag-v4-x86`, `set-unlock-flag-v5-x86` | Intermediate diagnostic binaries; corresponding source snapshots were not archived |
| `boot_dump_v8.c` | Later boot-dump experiment; no corresponding binary was archived |
| `logtool-script-writer/` | Experimental app that creates ASUS LogTool starter scripts; the final chain uses the bugreport carrier |

The version suffixes identify historical builds. They do not imply that an
experimental file is a newer replacement for the final implementation.
